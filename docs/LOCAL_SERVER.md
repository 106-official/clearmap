# ClearMap · 本地服务器部署详细步骤

> 目标：把后端跑在一台**常开笔记本**上（替代云服务器），手机 App 通过局域网或公网连上它来同步账号 / 打卡 / 路线 / 随笔等数据。
>
> 底图、景点、地图数据随 APK 内置，**后端未连上时地图与景点仍可离线使用**；连上后才支持登录、打卡、路线、随笔发布等需要账号的功能。

---

## 一、概念速览

| 部件 | 运行在哪里 | 作用 |
|---|---|---|
| App（APK） | 你的手机 | 地图 + 界面 + 离线底图 |
| 后端（`app.py`） | 常开笔记本 | 存账号 / 打卡 / 路线 / 随笔，对外提供 9100 端口 |
| 通信方式 | HTTP | 手机填后端地址 → 后端连接 |

后端地址是唯一要配置的东西——它在 App 的「个人 → 服务器 / 后端连接」里，存在手机本地（`localStorage`）。**搬家、换 IP、改端口都只需在 App 里改地址，无需重新打包。**

共两种用法，按你的网络情况二选一：

- **只用局域网**：手机与笔记本连同一个 Wi-Fi，填笔记本内网 IP。
- **要公网访问**（出门在外也能连）：再加一层「路由器端口映射」或「花生壳 / Nginx 内网穿透」。

---

## 二、第 1 步：在笔记本上装好 Python

1. 打开 [python.org/downloads](https://www.python.org/downloads/) 下载 Windows 安装包（Python 3.8+ 即可，推荐 3.10+）。
2. 安装时**务必勾选**「Add python.exe to PATH」。
3. 验证：打开「命令提示符」输入 `python --version`，能看到版本号即成功。

> 本项目后端零第三方依赖（只用 Python 标准库），装好 Python 就行，**不需要** pip install 任何东西。

---

## 二．第 2 步：取得后端程序

把 `clearmap` 项目整个放到笔记本上（任一路径均可），确认里面有这几个文件：

```
clearmap/
├── app.py            # 后端入口
├── config.py         # 配置（端口、短信、云同步等）
├── data/             # 运行后自动生成：账号 / 用户数据
└── deploy/
    └── start_laptop.bat   # 一键启动脚本
```

---

## 三、第 3 步：启动后端

**推荐方式：双击** `deploy\start_laptop.bat`

它会：
- 以 `0.0.0.0:9100` 监听（允许局域网 / 公网访问）；
- 优先用当前 `python`，找不到再找常见安装路径。

**命令行方式**（在项目目录）：

```
python app.py            # 默认端口 9100
python app.py 8080       # 想换端口就这样，下面所有 9100 请相应替换
```

看到一行：

```
ClearMap 已启动 →  http://0.0.0.0:9100
```

即启动成功。**这个窗口要一直开着**，关掉服务就停了。

> 首次以 `guest` 访问时会自动建号；账号数据随使用自动写入 `clearmap\data\`。

---

## 四、第 4 步：拿到你的地址

### 4A. 只想局域网用（最简单）

1. 在笔记本上按下 <kbd>Win</kbd>+<kbd>R</kbd>，输入 `cmd` 回车；
2. 输入 `ipconfig`，找到「以太网 / 无线局域网适配器」下的 **IPv4 地址**，形如 `192.168.1.20`；
3. 你的后端地址就是 `http://192.168.1.20:9100/`。

> 换 6A/7A 之间也可能用到它。

### 4B. 想要公网访问（可选，出门也能连）

- **方式一（路由器端口映射）**：在路由器管理页把「公网端口 9100 → 笔记本内网 IP:9100」。
  1. 具体入口各路由器不同（一般叫「端口映射 / 转发 / NAT」）；
  2. 公网地址通常是 `http://<你的公网IP>:9100/`（IP 可在设备“控制面板→网络和Internet”或搜索引擎查“我的IP”）；运营商拨号可能动态换 IP，长期使用建议配 DDNS。
- **方式二（内网穿透）**：用花生壳 / Nginx / frp 等，把笔记本 9100 映射到一个固定域名。

> 后面「验证」章节会教你如何确认通了。

---

## 五、第 5 步：放行 Windows 防火墙（局域网 / 公网都需要）

默认情况下 Windows 会拦截别的设备访问 Python 服务：

1. 打开「控制面板 → Windows Defender 防火墙 → 高级设置」；
2. 左侧点「入站规则」→ 右侧「新建规则」；
3. 「规则类型」选**端口** → 「TCP」→ 特定本地端口填 `9100`；
4. 操作选**允许连接**（如果想更精细，可勾选“配置文件”里的“专用”）；
5. 命名如 `ClearMap 9100`，完成。

---

## 六、第 6 步：在手机 App 里填地址

1. 打开 App，首页点进去 → 切到底部「**个人**」tab；
2. 找到「**服务器 / 后端连接**」卡片；
3. 在输入框填好后端地址，**末尾要带 `/`**，例如：
   - 局域网：`http://192.168.1.20:9100/`
   - 公网：`http://your-dns-or-ip:9100/`
4. 点「**保存并重连**」；
5. 旁边出现绿色的「**已连接**」即成功。

> 地址保存在手机本地。之后笔记本换 IP 了，只改 App 里这一处即可，**不用重装 / 重打包**。

---

## 七、第 7 步：验证是否真的通了

**在笔记本上**，打开浏览器访问下面任一地址，能看到 JSON 即后端正常：

```
http://127.0.0.1:9100/api/health
```

**在手机浏览器**（同一网络）访问局域网地址：

```
http://192.168.1.20:9100/api/health
```
能看到 `{"ok": true, "status": "up"}` 就说明手机能连上后端。

然后回 App 试一遍完整链路：`个人 → 登录（验证码）→ 发布一篇随笔 → 切到「发现」`，能看到自己的随笔，即可确认配置成功。

## 八、常见问题（FAQ）

| 现象 | 原因 / 解决办法 |
|---|---|
| App 显示「未连接」 | ①后端没启动 / 窗口被关；②地址末尾少 `/`；③防火墙没放行 9100；④手机与笔记本不在同一网络 |
| 局域网能连、公网连不上 | 路由器未做端口映射，或运营商未给公网 IP；改用内网穿透（方式二） |
| 换了 Wi-Fi 就连不上 | 笔记本内网 IP 变了；去 App 重填新地址，或给笔记本设「固定 IP」 |
| 手机浏览器能开、App 连不上 | 检查 App 里填的是不是同一个端口与地址、`/` 是否补全 |
| 想改端口 | 关掉服务，重新用 `python app.py <新端口>` 启动，App 里同步改地址 |

## 九、数据与迁移

- 所有账号数据都在后端笔记本的 **`clearmap\data\`** 目录：
  - `users/<user_id>.json` — 每个用户的资料 / 收藏 / 打卡 / 路线 / 随笔
  - `accounts.json` — 手机号 → 用户
  - `sessions.json` — 登录会话
  - `uploads/<user>/` — 上传的头像、打卡照片、随笔图
- **换笔记本 / 想备份**：把这个 `data` 目录整体复制过去即可（服务停止时复制更安全）。
- **开机自启（可选）**：把 `deploy\start_laptop.bat` 的快捷方式放进“启动”文件夹，或用计划任务，开机后自动拉起后端。

---

## 十、安全提醒

- 9100 是明文 HTTP。若暴露在公网，建议放在 **Nginx / Caddy 反向代理 + HTTPS** 后面。
- 登入后账号数据由**密码即验证码**保护（5 分钟有效、5 次上限、60 秒节流）。
- `data/` 包含用户隐私，注意别把它放进可公开访问的目录。
